# Visualization Modules

This folder contains standalone visualization tools and lightweight production
metadata for audience-facing research demos.

## Modules

- `llm_mlp_efficiency/` - Three.js visualization of Qwen3.5 0.8B FFN layers and
  RWKV-7 0.1B recurrent mix layers, with same-prompt comparison, per-layer
  MFLOPs/token, Delta/MFLOP, and narrated 4K conclusion-generation scripts.
