# Reproduction Guide

This guide assumes you are inside `rwkv_manifold_steering/`.

## 1. Install

```bash
python -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

For RWKV, provide a local RWKV-7 0.1B `.pth` checkpoint:

```bash
export RWKV_MODEL_PATH=/path/to/rwkv7-0.1b.pth
```

If `RWKV_MODEL_PATH` is not set, the scripts look for:

```text
models/rwkv7-0.1b.pth
```

For Qwen/Hugging Face gated models:

```bash
huggingface-cli login
```

or set:

```bash
export HF_TOKEN=...
```

## 2. Smoke Test

```bash
bash scripts/run_smoke.sh
```

## 3. Matched-Endpoint Runs

Run all four report cases:

```bash
bash scripts/run_matched_report.sh
```

Or run individual cases:

Weekday, RWKV:

```bash
python -m rwkv_manifold_steering.cyclic_manifold \
  --backend rwkv \
  --task weekday \
  --out-dir outputs/report_weekday_rwkv_matched \
  --start Monday \
  --end Thursday \
  --linear-endpoint-mode matched
```

Weekday, Qwen:

```bash
python -m rwkv_manifold_steering.cyclic_manifold \
  --backend qwen \
  --task weekday \
  --out-dir outputs/report_weekday_qwen_matched \
  --start Monday \
  --end Thursday \
  --linear-endpoint-mode matched
```

Month, RWKV:

```bash
python -m rwkv_manifold_steering.cyclic_manifold \
  --backend rwkv \
  --task month \
  --out-dir outputs/report_month_rwkv_matched \
  --start January \
  --end April \
  --linear-endpoint-mode matched
```

Month, Qwen:

```bash
python -m rwkv_manifold_steering.cyclic_manifold \
  --backend qwen \
  --task month \
  --out-dir outputs/report_month_qwen_matched \
  --start January \
  --end April \
  --linear-endpoint-mode matched
```

## 4. Compare Models

```bash
bash scripts/compare_rwkv_qwen.sh
```

## 5. Regenerate Report Assets

Most assets are generated by `cyclic_manifold.py` and `reporting.py` during the runs. Selected saved outputs are included under:

```text
reports/manifold_report/
```

For a full local package including video outputs, regenerate:

```bash
python -m rwkv_manifold_steering.audience_video --repo . --profile narrated
python scripts/generate_audience_minimax_audio.py
```

MiniMax TTS requires `MINIMAX_API_KEY` and usually `MINIMAX_GROUP_ID`. Keep credentials outside git.

## 6. Expected Metrics

Expected matched metrics are stored in:

```text
reports/manifold_report/metrics.json
```

Exact values can vary with model versions, CUDA/kernel behavior, tokenizer/model revisions, and dependency versions.

The important invariant in the corrected runs is:

```text
endpoint_hidden_l2_start = 0
endpoint_hidden_l2_end = 0
endpoint_behavior_l1_start = 0
endpoint_behavior_l1_end = 0
```

That confirms that linear and manifold paths share identical endpoints.
